# streamstats — потоковый анализатор файлов (лабораторная работа 2)

Программа читает файлы событий (CSV или JSONL) **построчно**, не загружая файл
в память целиком, и составляет статистический отчёт в формате JSON.

## Модель события

Каждая запись (строка) обязана содержать четыре поля:

| Поле        | Что это                                        |
|-------------|------------------------------------------------|
| `timestamp` | время события в формате ISO 8601               |
| `level`     | один из уровней: DEBUG, INFO, WARNING, ERROR, CRITICAL |
| `source`    | источник события (непустая строка)             |
| `message`   | текст сообщения                                |

## Установка и запуск

```bash
pip install -e .
```

## Команды

```bash
python -m streamstats analyze INPUT [INPUT ...] --format csv|jsonl --output REPORT.json
python -m streamstats analyze INPUT --format jsonl --skip-invalid
```

Что посчитано в отчёте:

- общее число событий;
- сколько событий каждого уровня;
- сколько событий каждого источника;
- топ-5 источников по ошибкам (уровни ERROR и CRITICAL);
- первая и последняя временные метки;
- число пропущенных строк (в режиме `--skip-invalid`).

Статистика нескольких файлов объединяется в один отчёт.

## Поведение при ошибочных строках

- **По умолчанию**: обработка останавливается, печатается номер файла и строки,
  CLI завершается с кодом `2`.
- **С ключом `--skip-invalid`**: плохая строка пропускается, в лог пишется
  WARNING, а число пропусков добавляется в отчёт.

    __main__.py         # разбор аргументов командной строки (CLI)
